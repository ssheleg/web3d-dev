# Docs study — web 3D stack (three r186 WebGPU/TSL, glTF assets, animation, R3F 9)

Check date for every row: **2026-09-27**. Versions studied (npm, 2026-09-27): `three@0.186.1` (REVISION `'186'`,
`three@0.186.1:src/constants.js:1`), `@react-three/fiber@9.8.1`, `@react-three/drei@10.7.9`, `three-stdlib@2.36.1`
(drei's loader dependency), `@gltf-transform/cli@4.5.0` (+ `functions`, `extensions` 4.5.0), `gltfpack@1.3.0`,
`meshoptimizer@1.3.0`, `@dimforge/rapier3d-compat@0.21.0`, `three-mesh-bvh@0.9.15`.

## Method

- Tarballs fetched with `npm pack <pkg>@<ver>` and grepped. A row citing `pkg@ver:path:line` was read at that line
  in the published tarball, not recalled.
- three.js examples were read from the **r186 tag**:
  `https://raw.githubusercontent.com/mrdoob/three.js/r186/examples/<name>.html` (abbreviated below as `ex:r186/<name>`).
- The r186 release notes came from `gh release view r186 -R mrdoob/three.js` (published 2026-09-24T14:35:44Z). The
  Migration Guide came from `https://github.com/mrdoob/three.js/wiki/Migration-Guide`, and R3F docs from context7
  `/pmndrs/react-three-fiber` (source `docs/API/canvas.mdx`).
- Abbreviations: `T:` = `three@0.186.1:`, `R3F:` = `@react-three/fiber@9.8.1:dist/events-9ce18a08.esm.js:`,
  `DREI:` = `@react-three/drei@10.7.9:`, `GT:` = `@gltf-transform/cli@4.5.0:src/`.
- **UNVERIFIED** means the claim was not confirmed against a primary source during this study.
